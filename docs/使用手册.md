# 盈亏透镜 · 使用手册

盈亏透镜是给快递网点管理员用的**客户发件盈亏分析工具**。把盈亏分析系统导出的「单号明细」拖进来，几秒钟就能看到：客户的报价是怎么定的、对不对；哪些流向、哪些重量段赚钱或亏钱；扣掉网点自己的线下成本后还剩多少纯利；调价后利润会怎么变。

> 🔒 所有计算都在你电脑的浏览器里完成，数据**不会上传**到任何服务器。关掉页面数据即清除。

---

## 一、5 分钟上手

1. **导出数据**：在网点发件盈亏分析系统中选择客户 → 单号明细 → 导出 Excel（.xlsx）。数据多可以按月分几次导出。
2. **打开工具**：双击 `ProfitLens.html`（或打开在线地址），推荐 Chrome / Edge / Safari 最新版。
3. **导入**：把一个或多个导出文件拖到页面中间。百万行数据通常 10 秒内完成。
4. **确认线下成本**（重要）：页面顶部黄色提示条默认按 **0.35 元/票**（客服、操作、运输、管理）估算纯利，可改成本网点的实际数。
5. **看分析**：依次浏览各页签；每个关键数字旁的 **ⓘ** 角标可以查看计算公式和数据来源。
6. **导出分享**：每张图右上角「⤓ PNG」导出高清图片；顶部「⤓ 导出 PDF」导出当前页或完整报告。需要发给客户或外部时，先勾选顶部「匿名」。

没有数据也可以点「先用示例数据看看」体验全部功能（示例数据为虚构）。

## 二、各页签说明

### 0. 客户总览（导入全网点数据时出现）
导出文件里有多个结算对象（例如全网点 10/1–10/8 的数据）时，会先打开这一页：
- **全网点指标**：结算对象数、票数、毛利、纯利、纯利为负的客户数。
- **按结算对象类型**：直营客户、下级网点、业务员、无对象分别统计。单票收入远低于平均的类型（如「无对象」）收入大多不在本系统结算，看直营客户的真实盈亏时可在筛选条「结算对象类型」里去掉。
- **报价执行核对（全部客户）**：
  - 有价格表的客户：上传网点的客户价格表（一个工作表一个客户），自动匹配结算对象，逐单核对实收运费是否按价格表执行，汇总一致率、少收、多收金额。只靠括号里的别名匹配上的客户会标黄，请确认；匹配错了可在明细表的「核对依据」下拉框里改。
  - 没有价格表的客户：**以系统实际收费为准**，不计多收、少收。工具会按该客户自己的收费规律还原出报价，偏离规律的单只作参考（常见原因是中转费未入账）。
  - **以系统收费为准的省份**（默认「北京」）：价格表可能没及时同步（如北京加收），这些省份与价格表不同的单记为「以系统为准」，不计差异。可在卡片上修改，多个省份用顿号分隔。
  - **补全价格表**：把没有价格表的客户按系统实际收费还原，按网点价格表的版式导出 Excel（一个客户一个工作表），核对后可直接贴进价格表。重货样本不足的续重会留空并注明。
- **客户纯利排行、客户象限图**：谁量大但亏钱，优先谈价。
- **客户明细**：可按票数、总纯利、单票纯利、一致率、少收金额排序，搜索，导出 Excel；点「查看」进入该客户的各个分析页。

### 1. 经营总览
- **核心指标**：票数、收入、成本、毛利、线下成本、纯利、亏损票占比。
- **单票利润拆解**：一票货的钱怎么来、怎么花：单票收入 → 减中转、派费、面单、增值成本 → 加政策补贴 → 单票毛利 → 减线下成本 → 单票纯利。
- **自动结论**：根据当前筛选自动写出票量集中在哪、哪些流向/重量段亏损、利润贡献最大的流向。
- **每日票量 / 每日单票利润**：看有没有异常波动的日子。
- **收入与成本构成**：每项的合计、单票和占比。

### 2. 流向 × 重量利润
- **热力矩阵**：行是省份、列是重量段，格子颜色表示所选指标（红 = 亏损，蓝 = 盈利）。可切换单票毛利/纯利、总毛利、毛利率、票数等。少于 5 单的格子不着色，避免被个别单误导。悬停格子查看完整收支。右上角「明细表」导出 Excel。
- **各重量段单票收支**：柱子是单票收入和成本，线是单票利润，一眼看出哪个重量段收不抵支。
- **省份利润排行**：按总额或单票排序。
- **0.1kg 精细利润曲线**：精确找到利润由正转负的重量点，是调整重量段报价的依据。
- **流向象限图**：横轴票量占比、纵轴单票利润。右下角（量大但亏钱）的流向应优先调价。

### 3. 结构占比
- 平均重量与 P50/P80/P90/P95 分位数（例如「90% 的单不超过 1.1kg」）。
- 重量段票量占比（含累计）、0.1kg 重量分布。
- 流向分布地图（省份瓦片图，可切换为单票利润地图）、省份排行、大区占比。
- 面单账号占比（同一客户的不同店铺/平台）。
- 省份 × 重量段结构（占全部 / 省内构成）。

> 这一页只需要「目的地」和「结算重量」两列，即使数据里没有收入、成本、利润也能用。

### 4. 报价还原与核对

> 报价按客户定。筛选范围里有多个结算对象时，本页会先请你选一个客户。
**系统还原的报价**：工具根据每单的运费（面单收入 + 中转收入）和重量，自动反推出客户的报价表：
- 识别重量段分界点（如 1.2 / 1.5 / 2 / 3kg）；
- 把价格相同的省份归成分区（如「一区」「京沪」「偏远」「新藏」）；
- 拟合续重公式，例如「>3kg：6 + 1 × ⌈重量 − 3⌉」表示 3kg 以上每超 1kg（不足 1kg 按 1kg）加 1 元；「按实重」表示不取整。
- **覆盖率**表示多少单的运费能被这张表完全解释。

**调价识别**：如果客户在导出时间范围内调过价（例如 8 月 6 日起面单费从 2.0 降到 1.8），工具会自动分成几个价格时段，分别还原，并在页面顶部提示，可切换查看。

**用网点价格表核对**（推荐）：在「客户总览」上传价格表后，选中某个客户时本页会自动用它对应的工作表核对，并显示：生效日期（之前的单不参与核对）、单号先付金额、报价单里的地市特价和解析提示、报价单原文备注。

**价格表能识别的写法**：
- 版式一：「城市 | 0-1.2kg | 1.21-1.5kg | … | 3kg以上面单款 | 3kg以上（0kg开始）」，下方「省份 | 1KG以内 | 1KG以上」为新疆、西藏。3kg 以上 = 面单款 + 续重单价 × 整公斤数（从 0kg 开始，向上取整）。
- 版式二：「省份 | 重量≦1kg | … | 首重 | 续重」，行首为「浙江、安徽、上海、江苏」这类分组，空白单元格视为与上一行合并；续重按备注里的「价格=首重+（重量-1）*每公斤价格」计算。
- 备注里的「北京上海加收 1 元/票」「新疆西藏件首重 15 元，超重 1KG 按首重 15 元、续重 15 元/公斤」「单号先付 X 元」「X 年 X 月 X 日实施」会自动识别。
- 识别不了的约定（如「北京 5KG 以上续重加收 1 元/公斤」「每日发件需达 4000 票」）会列在提示里，相关的单会显示为多收/少收，请人工判断。

**没有价格表的客户**：本页显示「系统还原的报价（以系统实际收费为准）」，可点「⤓ 价格表版式」按网点价格表的格式导出，补进价格表。

**用单个报价文件核对**：
1. 点「⤓ 报价模板」下载 Excel，模板已按还原结果预填；
2. 对照客户正式报价单修改（填写说明见模板第二个工作表）；
3. 点「⤒ 上传报价」，工具逐单比对：
   - **一致**：实收 = 按报价应收（容差 ±0.005 元）；
   - **多收**：实收高于报价；
   - **少收**：实收低于报价，是网点的直接损失；
   - **无报价**：报价表没覆盖到的省份或重量。
4. 「例外单」列出差额最大的单，「导出差异清单」得到完整 Excel，可直接拿去和财务、系统核对。

**报价模板格式**：每行一个分区（或一个省份），省份用顿号分隔；重量段列名写上限，如「≤1.2」「1.2-1.5」；续重五列：续重起点(kg)、续重基价(元)、续重单价(元/kg)、续重取整（向上取整 / 向上取整0.5 / 按实重）、续重计重起点(kg)。运费 = 基价 + 单价 × 取整(重量 − 计重起点)。例：「3kg 以上 = 面单款 3 元 + 单价 × 整公斤数」→ 起点 3、基价 3、计重起点 0。

### 5. 调价模拟
- 在报价表上直接改价，**立即**看到毛利、纯利、客户平均运费的变化；可「全部加价/降价 X 元」。
- **参考价（成本加成）**：参考价 = 该格子的单票成本（不含增值）+ 单票线下成本 + 目标单票利润（或按目标毛利率反推），向上取到 0.1 元。可一键「按参考价填入」。适合给同类新客户快速报价，或找出低于成本的格子。
- 改好的报价可「导出报价」保存，下次在核对页上传继续使用。
- 模拟假设货量结构不变，涨价可能导致客户货量流失，请结合实际判断。

### 6. 数据质检
检查收入、成本、利润三组勾稽关系，统计重量为 0、运费为 0、目的地无法识别、运单号重复、退件、自发自签、未发货等情况，并显示字段识别结果和可用功能。

### 特殊区域提示（⚑）
省内个别城市、海岛、偏远地区成本异常时，用「⚑」标在流向热力图、省份排行、地图、报价表上，悬停查看说明。**只做提示，不改变省份价格和统计。**提示有三个来源，在「流向 × 重量利润」「结构占比」「报价」页顶部的「特殊区域提示」条展开可看：
- **数据**：自动分析派费。导出只有省份、没有城市，但派费按实际派送城市结算，所以同一省份里若有一部分单派费明显偏高，说明省内有高成本城市或偏远地区（判定：0.3–1kg 正常件中，派费比本省常见水平高 0.25 元以上的单占 1% 以上、且摊到每票的额外派费 ≥ 0.015 元）；全省派费比各省常见水平高 0.15 元以上的也会提示（偏远省份除外）。
- **价格表**：客户报价单里单独报价的地市（如四川甘孜、阿坝、凉山）。
- **网点**：网点经验备注（如深圳、广州、舟山海岛），点「编辑网点备注」修改，每行一条「省份：备注」，保存在本机。

## 三、口径说明

| 指标 | 计算 | 来源 |
| --- | --- | --- |
| 收入（发件收入） | 中转收入 + 面单收入 + 增值收入 | 神州 - 财务工作台 - 发件费用账单 |
| 中转收入 | 发件应结金额 + 汇总计费的中转费 | 发件费用账单「应结金额」；分层报价「有/无指标-汇总计费」日/月账单 |
| 面单收入 | 单号明细面单费（收入 - 预收） | 发件费用账单 |
| 增值收入 | 退件费、拦截费、代收货款/到付款手续费、保价费、回单费、好快/标快费用中已向下结算的部分 | 发件费用账单 |
| 成本（发件成本） | 中转成本 + 派费成本 + 面单成本 + 增值成本 + 政策费用 | 网点发件过程中承担的费用 |
| 中转成本 | 中转费 − 密度返利 + 旺季中转费 + 建包费 + 扫描费 + 包月费 + 操作费 + 装车费 + 卸车费 | 同上 |
| 派费成本 | 基础派费 + 续重派费 + 区域加收 + 二级中转费 − 二级中转密度返利 + 增值派费 | 同上 |
| 面单成本 | 面单购买成本 | 同上 |
| 增值成本 | 代收/到付手续费 + 退件费 + 拦截费 + 保价费 + 好快/标快 + 回单费 | 同上 |
| 政策费用 | 中转费政策 + 面单政策 + 业务治理政策 + 其他政策；补贴为负、扣款为正 | 同上 |
| 毛利 | 收入 − 成本（系统「利润」） | 盈亏分析系统 |
| 线下成本 | 元/票 × 票数 + 固定总额（按票数分摊） | 使用者设置 |
| 纯利 | 毛利 − 线下成本 | 计算 |
| 运费（报价口径） | 面单收入 + 中转收入（不含增值） | 用于报价还原与核对 |

**重量段**一律「左开右闭」：1.2kg 属于「≤1.2」，1.21kg 属于「1.2–1.5」。单个客户的数据默认用其报价还原出的分界点；多个客户的数据默认用网点价格表最常用的分界（0.5、1、1.2、1.5、2、3、5、10）。可在页面上方「重量段」输入框修改（自动保存在本机）。

## 四、常见问题

**问：文件很大，导入会不会卡死？**
答：解析在后台线程进行，界面不卡。100 万行约 10 秒，内存占用约 300MB。建议使用 Chrome / Edge。

**问：提示「旧版 .xls 格式」？**
答：用 Excel 打开后「另存为」.xlsx 或 .csv 即可。

**问：我的导出没有收入/成本列，能用吗？**
答：能。只要有目的地和重量，就能用「结构占比」做流向和重量段分析。

**问：表头和系统导出不一样怎么办？**
答：导入时如果认不出「目的地」或「结算重量」，会弹出「确认字段对应」让你手动选择每一列。

**问：为什么还原的报价有「低置信」⚠ 标记？**
答：该分区的重货样本太少（比如只有一单 3kg 以上），续重单价无法从数据唯一确定，是参考同客户其他分区推断的，请对照正式报价单确认。

**问：线下成本怎么估？**
答：默认按 0.35 元/票（客服、操作、运输、管理成本）。也可以把网点一个月的这些费用加总，除以当月总票量得到「元/票」；某个客户专属的费用（如驻场人员）填到「固定总额」。设置会保存在本机浏览器。

**问：价格表里有些客户没匹配上？**
答：匹配按名称进行：先比较去掉括号和 K1、CK 等后缀的核心名称，再比较括号里的别名。没匹配上或匹配错的，在「客户总览 → 客户明细」的「报价表」下拉框里手动选。

**问：怎么分享给同事？**
答：把 `ProfitLens.html` 这一个文件发给同事（微信、U 盘均可），双击就能用，Windows 和 Mac 都可以；或者直接发在线地址。数据文件需要单独发送。

**问：截图发给客户会泄露其他信息吗？**
答：先勾选顶部「匿名」，客户名称和面单账号会显示为代号；导出的 PNG/PDF 也会使用代号。
